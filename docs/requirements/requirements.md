# StudyHub

## Obiettivo
Studyhub è una piattaforma pernsata per aiutare gli studenti universitari ad organizzare al meglio lo studio e gestire tutto la parte riguardante gli esami.

L'utente può:
- gestire i vari corsi universitari;
- pianificare gli esami e lo studio;
- salvare appunti;
- creare degli obiettivi giornalieri per progredire nello studio;
- monitorare i progressi;

## Tecnologie 

### Backend
- Java 21
- Spring boot
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React
- Typescript

### IDE e altro
